Case-data convention
--------------------
- The base data are the classic 10-firm Grunfeld investment panel.
- Original Grunfeld years 1935-1954 are relabelled 2006-2025 only as
  sequential teaching-period identifiers.
- invest  = real gross investment.
- value   = real market value of the firm.
- capital = real stock of plant and equipment.
- Raw monetary levels are in millions of 1947 dollars.
- The base file contains no native binary, count, fractional, ordered,
  censored, selected, or duration outcome.
- The binary case is therefore explicitly derived as:
      pos_invest_growth_it = 1[Delta ln(invest_it) > 0]
- Count and other limited-outcome models remain conceptual because the base
  data do not contain defensible native outcomes of those types.

Current EViews documentation checks
-----------------------------------
1. Equation::binary
   - Syntax: eq_name.binary(options) y x1 [x2 ...].
   - d=l specifies logit; d=n specifies probit.
   - cov=cr requests cluster-robust covariance.
   - crname=series specifies the one-way cluster identifier.
   - crtype=cr1 is the documented finite-sample cluster weighting default.
   - m=integer sets the maximum number of iterations.
   - The documented binary method is a general single-equation estimator;
     panel fixed/random effects are not automatically invoked by workfile
     structure.

2. Equation::fit
   - For binary models, default fit saves fitted probabilities.
   - fit(i) saves the fitted index.
   - Logistic density @dlogistic(index) can be used for manual AMEs.

3. Equation::predict
   - Displays the binary prediction/classification table.
   - The success cutoff defaults to 0.5 and may be supplied explicitly.

4. Equation::count / count
   - Supports Poisson, negative-binomial, and count QML specifications.
   - Current documented covariance choices include ordinary, Huber-White, and
     GLM methods.
   - The current count syntax does not list binary's cov=cr/crname one-way
     cluster-robust option.
   - The standard count command does not automatically implement conditional
     fixed-effects Poisson merely because the workfile is panel structured.
