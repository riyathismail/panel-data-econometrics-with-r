# Chapter 14 companion R and data

Open the chapter folder as the working directory in RStudio (R 4.5.2).
Restore the recorded dependencies with `source("restore_environment.R")`,
then run `source("R/chapter14.R")`.
Internet access is required for dependency installation.

The companion contains local teaching data, code, dependency versions and
verification records. Running the code creates results, tables and figures.
The book manuscript and its LaTeX build are distributed separately.
See the package README for optional estimators and reference conventions.


The default sequential script `R/chapter14.R` passed a live R 4.5.2 execution on 11 October 2026. The included `renv.lock` records installed dependency versions. Restore these versions before running; see the release notes for optional estimators, preserved reference figures, and numerical tolerances.
