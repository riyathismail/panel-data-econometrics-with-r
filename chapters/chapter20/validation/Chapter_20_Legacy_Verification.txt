Dataset convention
------------------
- 10 firms x 20 sequential teaching-period labels = 200 level observations.
- Original Grunfeld years 1935-1954 are sequentially relabelled 2006-2025.
- The relabelled values are instructional period identifiers only.
- invest  = real gross investment.
- value   = real market value of the firm.
- capital = real stock of plant and equipment.
- Raw monetary variables are in millions of 1947 dollars.
- ginvest, gvalue and gcapital are first log differences and are dimensionless.
- First differencing leaves 190 usable observations (19 per firm).

Continuity note:
Chapter 15 selected the period-effects-only first-difference model as the principal

B. Classical joint interaction test
-----------------------------------
Unrestricted model:
  firm and period effects + common gvalue/gcapital + 18 firm-slope interactions.

Restricted R-squared   = 0.500977273
Unrestricted R-squared = 0.574789276
Restricted SSR         = 6.543589197
Unrestricted SSR       = 5.575706582
Unrestricted residual df = 142

Classical nested test:
  F(18,142) = 1.369426153
  p         = 0.155726828

Interpretation:
The classical test does not reject common slopes at conventional levels, but this
is not proof of exact equality. It is exact only under the classical independent
homoskedastic normal linear-model assumptions. A 18-restriction cluster-robust
Wald test with only 19 teaching-period clusters is nearly rank-saturated.

firm-specific intercept, adjustment coefficient and current gvalue/gcapital

H. Current EViews documentation verification
--------------------------------------------
Official current EViews documentation was checked for:

1. @demeanby
   - Returns deviations from group means.
   - Documented as panel aware.

2. @meansby and @sumsby
   - Return group means and group sums as linked series.
   - Used to form teaching-period CCE averages and leave-one-out averages.

3. Equation::testadd
   - Tests jointly whether listed omitted regressors should be added.
   - For linear LS, the classical F statistic is based on restricted/unrestricted SSR.

4. Panel LS syntax
   - cx=f requests cross-section fixed effects.
   - per=f requests period fixed effects.
   - cov=percluster requests period clustering.

5. Panel ARDL/PMG
   - equation.ardl(fixed,deplags=1,reglags=1) is documented panel ARDL syntax.
   - In this command, fixed means fixed lag lengths, not dynamic fixed effects.
   - PMG permits heterogeneous short-run coefficients/intercepts while pooling the
     long-run slope vector.

6. PMG diagnostics and data members
   - eq.srcoefs displays cross-section error-correction regressions.
   - eq.similarity and eq.pmghausmantest provide PMG Hausman similarity diagnostics.
   - @pmglrcoefs returns the pooled long-run vector.
   - @ardlsrcoefs / @ardlsrses return cross-section short-run coefficients / SEs.
   - @pmgcxcoefs / @pmgcxses are also documented cross-section EC coefficient matrices.
