# Chapter 24 R Package Notes

- `targets`: dependency-tracked production pipeline.
- `testthat`: executable numerical release assertions.
- `digest`: SHA-256 data/output hashes.
- `plm`: core panel estimators and specification tests.
- `sandwich`: covariance cross-checks.
- `modelsummary`: publication-table rendering after inference is computed explicitly.
- `renv`: post-run environment snapshot and restoration.

The statistical benchmark is defined by explicit formulas and hard assertions, not by formatting defaults.
