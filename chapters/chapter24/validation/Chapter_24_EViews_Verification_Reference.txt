Dataset convention
------------------
- 10 firms x 20 sequential teaching-period labels = 200 level observations.
- Original Grunfeld years 1935-1954 are sequentially relabelled 2006-2025.
- The labels are instructional period identifiers only; no modern event is
  attached to a relabelled date.
- invest  = real gross investment.
- value   = real market value of the firm.
- capital = real stock of plant and equipment.
- Raw monetary values are in millions of 1947 dollars.
- linvest/lvalue/lcapital are natural logs.
- ginvest/gvalue/gcapital are first log differences.
- First log differences leave 190 firm-period transitions.

EViews documentation verification
---------------------------------
Current official EViews documentation was checked for:

- wfopen:
    opens foreign data sources, including CSV, into a new workfile.

- pagestruct:
    pagestruct firm @date(year) is documented panel-structuring syntax.

- Panel LS:
    cx=f/r and per=f/r select cross-section and period effects.
    cov=percluster is period clustering.
    cov=cxcluster is cross-section/firm clustering.
    cov=bothcluster is two-way firm-period clustering.

- fixedtest:
    tests joint significance/redundancy of fixed effects.

- rcomptest:
    requires a pooled least-squares panel equation and reports random-component
    LM-type tests.

- ranhaus:
    must be run from a random-effects equation and compares against the
    corresponding fixed-effects model; robust-SE Hausman results require caution.

- cdtest:
    reports Breusch-Pagan LM, Pesaran scaled LM, Pesaran CD, and related panel
    residual dependence diagnostics.

- freeze(mode=overwrite,...):
    creates a named frozen output object and overwrites an existing object.

- spool.append(name=..., mode=overwrite):
    appends named output objects to a spool and can replace existing spool items.

- spool.save:
    supports PDF and LaTeX export, including A4 PDF output.

- wfsave:
    saves the default workfile as an EViews workfile.

- EViews program continuation:
    wrapped program lines use '_' rather than a backslash.
